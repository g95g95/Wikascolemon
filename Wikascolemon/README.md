# Wikascolemon

L'enciclopedia (immaginaria) dei Pokémon della vallata picena — schede fan-made nel formato di Pokémon Central Wiki, dedicate a personaggi legati alla topografia e all'immaginario dell'alta valle del Tronto e del Piceno.

**Sito live:** https://g95g95.github.io/Wikascolemon/
